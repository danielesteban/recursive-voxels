==

#### Local development

```bash
# clone this repo
git clone https://github.com/danielesteban/recursive-voxels.git
cd recursive-voxels
# install dependencies
pnpm install
# start the dev environment:
pnpm start
# open http://localhost:8080/ in your browser
```
